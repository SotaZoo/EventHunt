# Event discovery

Language for event discovery, recommendation reasons, and source information
distinct from a user's own registration.

## Language

**Public preview**:
The same server-selected next three eligible future events shown to anonymous
visitors. It is not the full catalog hidden by visual blur.

**Invitation request**:
An unverified email address submitted for manual access review, not an account
or approval.

**Invitation**:
Approval for a specific Google-linked email to access Event Hunt. An invitation
message communicates that approval; the ordinary sign-in link is not a credential.
Invitations are required for new members only when open Google sign-up is disabled.
_Avoid_: Message sent or delivered as synonyms for access approved.

**Highlight**:
A concise, source-supported, positive reason an event stands out. It is
distinct from a full fit explanation or an urgency reason.
_Avoid_: Negative fit explanation or why now as synonyms for highlight.

**Fit reason**:
An explanation of an event's match or lack of match to a preference profile.
Current Event Hunt fit uses a shared internal profile, not each user's personal
preferences.
_Avoid_: Personalized recommendation when describing shared fit.

**Urgency reason**:
An explanation of why learning about an event is time-sensitive, such as an
approaching date or a source-listed registration deadline. It is not an
explanation of the event's fit.
_Avoid_: Highlight or fit reason as synonyms for urgency reason.

**Urgency note**:
A source-supported registration deadline or scarcity fact that gives someone
a reason to act. An event happening soon is not sufficient for this card note.
_Avoid_: Event proximity alone as an urgency note.

**Registration availability**:
The source platform's observed registration options for an event, such as open
registration, a waitlist, full capacity, or closed registration.
_Avoid_: Registration status when referring to source availability.

**Waitlist availability**:
The source platform offers a way to request a place without confirming
attendance. This does not mean an individual user has joined the waitlist.
_Avoid_: Waitlisted when describing the event rather than a user's registration.

**Personal registration status**:
An individual user's relationship to an event, such as registered, awaiting
approval, or waitlisted. This is not registration availability.
_Avoid_: Event status when referring to a user's registration.

**Cancellation**:
An organizer-confirmed decision that an event occurrence will not take place,
rather than merely being postponed or rescheduled. Full capacity and closed
registration are not cancellations.
_Avoid_: Unavailable or sold out as synonyms for canceled.

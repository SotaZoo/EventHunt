# App design process

Start with the [primary user task](primary-user-task-and-user-flow.md).
Describe the behavior in terms of what people need to see or do. Keep
calendar navigation, filtering, availability, and source links in the
flow when reviewing a discovery change.

Use the [design system](design-system.md) and verify changes against the
running interface at desktop and mobile widths. Use the synthetic
catalog for review screenshots.

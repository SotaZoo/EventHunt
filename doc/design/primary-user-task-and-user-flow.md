# Primary user task and user flow

Find events worth considering and open their original listings with enough
context to decide what to do next.

1. Open the public preview or sign in.
2. Browse dates in the calendar and apply format, score, or time filters.
3. Read the event title, timing, venue or attendance format, fit, and any
   source-supported notes.
4. Open the organizer's listing for current availability and event details.
5. Use **Account → AI integration** to query the same catalog from an agent.

The [web guide](../development/web.md) explains presentation and the
[MCP guide](../development/mcp.md) explains agent setup and follow-up.

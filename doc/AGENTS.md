# Doc Agent Notes

Before editing docs, read [`.ai/AGENTS.md`](../.ai/AGENTS.md), then load
the relevant module from `.ai/`.

Docs are partitioned by audience:

- `doc/administration/` — runbooks, deploy, security, ops
- `doc/design/` — user tasks and user flows; a wireflow requires screen
  designs and interactions, not only a user-flow diagram
- `doc/development/` — architecture, API, web, database, testing, MCP

Temporary planning, design, and research artifacts may live in top-level
`scratch/`. That directory is ignored and local only. Do not cite it as current
project state or make tracked code/docs depend on it. Promote durable technical
guidance into the appropriate `doc/` page.

Before changing the Event Hunt Penpot design, read
[`design/app-design-process.md`](design/app-design-process.md) and
[`design/primary-user-task-and-user-flow.md`](design/primary-user-task-and-user-flow.md).

Use GitHub issues and pull requests to discuss changes to this source tree.

There is no `doc/plans/`, `doc/checkpoints/`, `doc/checklists/`,
`doc/architecture/`, or `doc/development/design_documents/`.
